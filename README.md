# Network Visualization Tool

This is a personal project for visualizing network ports and connections.
This will be the server that will handle the data and provide it to the front-end for visualization.

Some of the features include:
- Mapping of network ports and connections
- Verification of open ports
- Real-time updates of network activity

# Tools used:
## backend
- Python
- Docker
- Flask
- HTTP/JSON

## frontend
- React native
- TypeScript
